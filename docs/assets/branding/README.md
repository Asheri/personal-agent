# Sci RAG Kit logo pack

This pack uses the selected process-engineering logo without the database icon.
The emblem combines chemistry, biology, scientific literature, a knowledge
graph, an active lab flask, and simplified process equipment.

## Primary logo files

- `full-logo/`: horizontal color lockups on transparent, pure white, and pure
  black backgrounds.
- `icon/`: standalone square color marks on transparent, white, and black.
- `monochrome/`: black, white, and reversed one-color artwork.
- `icon-sizes/`: transparent square icons at 512, 256, 192, 180, 128, 64, and
  32 pixels.
- `source/`: the selected original white-background master.
- `sci-rag-kit-logo-system-overview.png`: visual reference sheet.

## Suggested use

- Use the transparent color files over light neutral backgrounds.
- Use the dedicated black-background files on true black or very dark surfaces.
- Use the monochrome artwork where printing or accessibility requires a single
  color.
- Use the standalone icon for avatars, app tiles, favicons, and social profiles.

The generated master is raster artwork. These exports are PNG assets, not
editable vector paths.

In this repository: the README header image (`../logo.png`) is a
size-optimized derivative of `full-logo/sci-rag-kit-full-color-white.png`,
and the docs site favicon and logo come from `icon-sizes/`.
